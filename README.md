# 粒界 Gesture Particle

一个可直接在 VS Code 里运行的 WebGL 手势粒子人物实验。

## 运行

推荐使用 VS Code 的 Live Server 扩展打开 `index.html`。

也可以在项目目录执行：

```bash
python -m http.server 5500
```

然后访问 `http://localhost:5500`。

## 操作

- 鼠标移动：控制三维视角与局部粒子场。
- 按住鼠标：粒子爆散；双击切换人物、爱心和星环。
- 人物模式：左右手掌分别驱动人物双臂，手部速度和高低差带动躯干倾斜与双腿摆动。
- 人物整体会轻微跟随双手中心移动，快速动作会产生明显的踏步、身体弹跳和头部摆动。
- 指尖触碰：食指靠近粒子时直接推开局部粒子场，两只手可以同时作用。
- 单手捏合：拇指与食指捏合后抓取并移动人物、爱心或星系。
- 双手捏合：两只手的中心移动物体，手距控制缩放，连线角度控制旋转。
- 单独伸出食指：移动手指可连续进行 360 度旋转；持续移动或把手靠近镜头，会放大星环并逐层推进镜头深度。
- 握拳会退出深层视角，恢复默认尺度和镜头距离。
- 握拳同时会让累计旋转按最短路径回到正面；也可以把食指移到画面中心并停留约半秒触发回正吸附。
- 星系形态：使用数学分布生成四种原创粒子结构，分别表现双极尘埃带、侧视薄盘、倾斜双旋臂和椭圆单旋臂，并为每种星系生成独立纵深。
- 张开手掌：粒子持续爆散；握拳：粒子快速回聚。
- 左右挥手：循环切换人物、爱心和四种原创星系，页面不显示形态标签。
- 捏合判定拥有最高优先级，不会与张手、握拳或挥动效果叠加。
- 导入自定义轮廓：选择本地图片，自动采样为粒子人物。
- 右上角圆点按钮：开始或停止 WebM 录制。

Three.js、手势识别库和模型都在项目本地，不依赖 CDN。浏览器会询问摄像头权限，视频只在本地页面中处理，不会上传。

摄像头模式使用低分辨率手势推理和独立的 60 FPS 粒子补间，避免识别帧直接拖慢动画帧。
